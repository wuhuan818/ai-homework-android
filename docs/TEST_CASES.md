# Test Cases

## Skeleton Smoke Tests

1. Build tasks are listed with `.\gradlew.bat tasks`.
2. Debug APK is generated with `.\gradlew.bat assembleDebug`.
3. App installs on a connected device with `adb install -r`.
4. App launches without crashing.
5. Create screen is visible by default.
6. Bottom navigation switches to Edit.
7. Bottom navigation switches to History.
8. Bottom navigation switches to Settings.
