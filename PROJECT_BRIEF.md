# Project Brief

## Overview

AIContentCreator is an Android AI application for the AI homework contest. The selected topic is an Android generative content creation tool.

## Current Delivery Goal

The current goal is to finish a minimum deliverable version in about one week. The app should be able to run on a real Android device, demonstrate a complete feature loop, and support a smooth contest presentation.

## Priorities

1. Real-device runnable APK.
2. Complete user flow from creation to edit, history/favorite, and share.
3. Clear demo evidence: screenshots, recording, build output, and install output.
4. Small, understandable implementation that can be finished under time pressure.

## Non-priorities

- Complex architecture.
- Over-engineered abstractions.
- Unrelated refactors.
- Account systems, cloud sync, or multi-model switching before the core demo is stable.
- Visual polish that delays the minimum viable demo.
