# AIContentCreator

面向 ISBG 2026 AI 作业比赛的 Android AI 内容创作助手。

## 项目目标

构建一个可在 Android 真机展示的 AI 内容创作 App，支持朋友圈文案、商品描述、图片描述、文本编辑、收藏历史、本地加密保存、图片基础处理和 Android 系统分享。

## 当前状态

已实现最小可用系统：

1. 演示模式 / 真实模型模式切换。
2. OpenAI-compatible Chat Completions 风格的大模型接口接入。
3. 图片选择与图片描述。
4. 文本编辑、Markdown / 纯文本转换、收藏、历史记录和系统分享。
5. Android Keystore + AES-GCM 加密保存模型密钥和历史内容。
6. 图片旋转 90°、文字水印、恢复原图和处理后图片分享。
7. 创作页、编辑页、历史页、设置页主要用户可见文案已中文化。
8. 设置页支持 3 个接口配置预设，图片描述支持 3 种描述风格。
9. 图片描述支持本地示例图片预览，真实图片描述上传前会自动准备识别副本，历史页支持收藏夹筛选、单条删除和清空确认。
10. App 内已减少说明型文案，工程说明和技术证明集中保留在 README / docs。
11. 设置页支持对当前启用配置执行文本模型连接自测。
12. 朋友圈文案和商品文案支持创作风格选择、风格推荐和生成 3 个版本。
13. 编辑页支持“更简短 / 更温柔 / 更高级 / 更口语 / 提炼标题”二次改写。

## 演示模式与真实模型模式

### 演示模式

- 使用本地 `MockModelClient` 模板生成内容。
- 输出会明确标注 `【演示模式生成】`。
- 不上传用户输入或图片。
- 适合离线演示、比赛讲解和基础流程验证。

### 真实模型模式

- 使用用户在设置页配置的接口地址、文本模型、图像模型和模型密钥。
- 调用 OpenAI-compatible Chat Completions 接口。
- 文本输入和已选择的图片会发送到用户配置的大模型接口。
- 图片描述会把用户补充要求一起发送给模型；未上传真实图片时，只会基于示例图片线索生成，并提示模型不要伪装成真实识图。
- 点击“使用示例图片”会加载一张内置小尺寸示例图；示例图会复制到 App cache 后作为普通图片 Uri 参与预览、演示描述和基础处理。
- 图片描述会在上传给模型前自动准备识别副本；大图会被压缩到更适合上传的尺寸和体积，HEIC、HEIF 或未知格式会尽量转换为 JPEG 副本。
- 压缩或转换只作用于发送给模型识别的副本，不覆盖用户选择的原图，也不替换旋转、水印或分享使用的图片文件。
- 鉴权失败、断网、超时、限流、服务异常或接口返回格式无法识别等真实 API 错误会明确提示，不会伪装成真实生成成功。
- 模型密钥不会在 UI 中完整展示，保存时通过 Android Keystore 加密。
- Settings 中的 3 个接口配置预设只用于保存和切换备用接口配置，不进行模型评分、测速或横向对比。
- 设置页“测试文本模型连接”只验证当前启用配置的文本模型接口，不保存历史，不做模型评分、测速或横向对比。

## Prompt 设计思路

### 朋友圈文案

支持 6 种创作风格：温馨日常、轻松幽默、简短高级、洒脱随性、文艺氛围、情绪表达。默认使用“温馨日常”。Prompt 会带入用户选择的风格，要求保持适合中文社交平台的表达，不编造事实，避免广告腔和空泛表达，并尽量保留用户输入的具体细节。

### 商品描述

支持 6 种创作风格：种草推荐、卖点清单、专业可信、促销转化、小红书风、短视频口播。默认使用“种草推荐”。Prompt 会带入用户选择的风格，建议按标题、核心卖点、适用人群、使用场景、短文案组织输出，并明确要求不编造事实、不夸大商品参数、功效、销量、价格或资质，保持适合中文电商平台或社交电商平台的表达。

### 风格推荐与多版本

- 在朋友圈文案和商品文案场景中，点击“帮我推荐风格”可根据输入内容返回 2 到 3 条推荐方向，每条包含风格名称和简短理由。
- 演示模式使用本地关键词规则推荐；真实模型模式使用当前配置的文本模型推荐。
- “生成 3 个版本”默认关闭。开启后，Mock 和 Real 都会生成 3 个清晰分隔、表达角度不同的版本。
- 风格推荐结果只展示在创作页，不保存到历史；生成结果会按完整文本保存到历史。

### 图片描述

支持 3 种描述风格：

1. 客观描述：输出画面主体、背景环境、颜色与氛围、可见细节，要求不编造图片中不存在的内容。
2. 社交配文：输出画面简述、自然社交配文和 3 到 5 个标签，避免广告腔。
3. 商品文案：输出可能的商品/主体、卖点表达、使用场景和短文案，要求不编造品牌、价格、参数或功效；无法判断商品时提示更适合普通图片描述。

图片描述 Prompt 会优先使用用户输入作为补充要求；如果输入为空，则使用已选择图片或示例图片线索。未上传真实图片时，Prompt 会明确说明只能基于文字线索生成。

## 隐私与合规说明

- 演示模式不上传内容，只使用本地模板。
- 真实模型模式会把输入内容发送到用户配置的大模型接口。
- 模型密钥仅在设置页输入，UI 只显示已配置 / 未配置，不展示完整密钥。
- 模型密钥通过 Android Keystore + AES-GCM 加密保存。
- 历史内容本地加密保存，生成内容不会直接以明文写入本地历史文件。
- 不要把真实 API Key 写入源码、Git 提交、README、文档、日志、截图或问题报告。

## 主要使用流程

1. 打开 App，进入“创作”页。
2. 选择朋友圈文案、商品描述或图片描述。
3. 在朋友圈文案或商品描述场景中选择创作风格，也可点击“帮我推荐风格”查看推荐方向。
4. 如需对比表达，可开启“生成 3 个版本”。
5. 在演示模式下直接生成演示内容，或在设置页配置模型密钥后切换到真实模型模式。
6. 查看创作结果，并可继续编辑、收藏、分享或复制。
7. 在编辑页可使用“更简短 / 更温柔 / 更高级 / 更口语 / 提炼标题”进行二次改写；改写结果进入文本框，点击保存后才更新历史。
8. 在图片描述场景中，可选择描述风格、选择图片或使用示例图片、旋转 90°、添加文字水印、恢复原图，并分享处理后的图片。
9. 在“历史”页查看本地保存的作品和收藏状态，可切换“全部 / 收藏夹”，也可删除单条历史。
10. 在“设置”页查看当前状态、模型模式、3 个接口配置预设、模型密钥状态和安全存储说明。
11. 如需检查真实模型配置，可点击“测试文本模型连接”。

## 真实模型配置

1. 打开“设置”页。
2. 将模型模式切换为“真实模型模式”。
3. 在“接口配置预设”中选择“默认配置”“备用配置一”或“备用配置二”。
4. 根据需要编辑配置名称、接口地址（Base URL）、文本模型（Text Model）和图像模型（Vision Model），并保存当前配置。
5. 输入当前配置的模型密钥（API Key）并点击“保存密钥”。
6. 点击“测试文本模型连接”，确认当前启用配置可用。
7. 回到“创作”页，确认顶部显示真实模型模式提示。

默认配置：

- 接口地址（Base URL）：`https://api.openai.com/v1`
- 文本模型（Text Model）：`gpt-4o-mini`
- 图像模型（Vision Model）：`gpt-4o-mini`

每个配置预设的模型密钥独立加密保存。设置页只显示“已配置”或“未配置”，不展示完整密钥。

配置自测说明：

- 自测使用当前启用配置的接口地址、文本模型和已保存密钥。
- 自测发送极短文本请求到 OpenAI-compatible Chat Completions 接口。
- 成功时显示“文本模型连接成功。”。
- 失败时显示可读错误，例如密钥缺失、接口地址错误、网络不可用或鉴权失败。
- 自测结果不保存到历史记录，不输出 API Key、请求体或返回体，不做模型评分、测速、排行榜或多模型对比。

## App 内信息架构

- 创作页只保留创作所需入口、模式提示、图片描述模块和结果操作。
- 编辑页在没有作品时显示空状态和下一步引导，有作品时再显示文本框与格式转换。
- 历史页突出作品列表和“全部 / 收藏夹”筛选，加密说明弱化为底部安全提示。
- 设置页优先展示当前状态和常用操作，接口字段、模型字段和密钥操作归入高级配置。
- 比赛说明、工程说明和技术证明集中放在 README / docs，不占据 App 主界面。

## 图片基础处理验证

1. 安装 debug APK 并打开 App。
2. 进入“图片描述”场景。
3. 切换“客观描述”“社交配文”“商品文案”描述风格，确认当前风格提示变化。
4. 点击“使用示例图片”，确认预览区域显示内置示例图。
5. 点击“选择图片”，选择一张设备图片。
6. 如果图片较大或格式需要转换，生成图片描述后确认创作页出现“图片已转换/压缩用于识别，可能对细节识别有一定影响。”提示，并说明压缩/转换只用于识别、不覆盖原图。
7. 点击“旋转 90°”，确认预览和状态更新为处理后图片。
8. 输入水印文字，点击“添加水印”，确认处理后的预览和状态更新。
9. 点击“恢复原图”，确认预览回到原图且状态提示为“已恢复为原图。”。
10. 点击“分享图片”，确认 Android 系统分享面板打开。
11. 未选择图片时点击图片处理操作，应看到中文提示。

## 加密历史验证

1. 使用演示模式生成包含可识别短语的内容，例如 `LOCAL-VERIFY-2026`。
2. 收藏结果，或进入编辑页保存修改。
3. 关闭并重新打开 App，确认“历史”页仍显示作品。
4. 检查 debug SharedPreferences，确认可识别短语没有以明文出现。

可用命令：

```powershell
adb shell run-as com.aihomework.aicontentcreator ls shared_prefs
adb shell run-as com.aihomework.aicontentcreator cat shared_prefs/ai_content_creator_history.xml
```

如果设备不支持 `run-as`，可使用 Android Studio Device Explorer 查看 debug 包的 `shared_prefs` 目录。

## 当前限制

- 当前支持 3 个 OpenAI-compatible 接口配置预设，但只启用其中一个配置进行单次调用，不做多模型对比、评分、测速或排行榜。
- 图片描述能力取决于用户配置的服务是否支持 vision 输入。
- 大图或不兼容格式会在上传给模型前生成压缩 / 转换后的识别副本，可能对细节识别有一定影响。
- 真实 API 错误不会静默降级为演示结果；只有图片读取、图片过大、格式不兼容或 Vision 能力不支持等图片能力问题会使用演示模式兜底，并明确标注。
- 历史记录以单个本地加密 JSON blob 保存，适合比赛阶段展示，不适合大量数据检索。
- 历史页只提供“全部 / 收藏夹”筛选、单条删除和清空确认，不做复杂分类或相册管理。
- 图片处理仅包含旋转和文字水印，处理后图片保存于 App cache，不作为永久相册导出。
- 当前没有账号系统、云同步、图像生成功能、复杂图片编辑器或应用商店发布流程。
- 本阶段明确未加入图像生成功能；后续只有在产品目标和安全边界明确后才评估。
