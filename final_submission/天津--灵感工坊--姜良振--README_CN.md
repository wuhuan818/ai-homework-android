# 灵感工坊 README

## 项目信息

- 项目名称：灵感工坊
- 选题：选题二，安卓应用生成式内容创作工具
- GitHub 仓库：https://github.com/wuhuan818/ai-homework-android
- 最终分支：stage15-final-submission
- APK：天津--灵感工坊--姜良振--APK-debug.apk，debug 构建，用于作业评审安装。

## 项目目标

灵感工坊面向 Android 真机演示，目标是完成一个小而完整的生成式内容创作闭环：用户输入创作需求，应用在演示模式或真实模式下生成结果，用户可以编辑、改写、收藏、查看历史、分享文本或图片，并能对导入图片或生成图片做基础处理与保存。

## 非目标

本版本不做账号系统、云同步、应用商店上架、自研模型、多模型评分排行、图生图、局部重绘、涂鸦、多图批量生成或专业图片编辑器。图片处理只覆盖比赛要求所需的基础能力，不扩展为复杂设计工具。

## 完成判据

1. APK 可构建，并可在评审设备上安装测试。
2. 至少覆盖朋友圈文案、商品描述、图片描述、图片生成四类创作场景。
3. 支持“输入 -> 调用模型或演示生成 -> 展示结果 -> 编辑 -> 收藏 / 分享”的主链路。
4. 支持文本二次改写、Markdown / 纯文本转换、历史记录和收藏夹。
5. API Key、文本历史和新生成图片文件使用本地加密存储方案保护。
6. 提供构建日志、APK 信息、验证路径和待补充截图/录屏清单。

## 核心功能

- 文本创作：朋友圈文案、商品描述、风格选择、风格推荐、可选生成 3 个版本。
- 图片描述：选择本机图片或内置示例图，支持客观描述、社交配文、商品文案三种描述风格。
- 图片生成：根据文字提示生成图片，支持图片风格、画幅比例、提示词优化、文本结果生成配图入口。
- 文本编辑：支持更简短、更温柔、更高级、更口语、提炼标题等改写候选，并在用户确认后应用。
- 格式转换：支持 Markdown 与纯文本互转。
- 图片基础处理：旋转 90 度、文字水印、黑白滤镜、中心裁剪、框选裁剪、恢复原图、分享处理后图片。
- 作品管理：历史记录、收藏夹、再次使用、再次生成、系统分享、保存生成图片到相册。
- 模式切换：演示模式使用本地模板；真实模式调用用户配置的大模型接口。
- 配置管理：设置页支持 Base URL、API Key、Text Model、Vision Model、Image Generation Endpoint、图片生成模型和多配置预设。

## 真机运行方式

1. 使用 Android Studio 打开仓库，或在项目根目录执行 `.\gradlew.bat assembleDebug`。
2. 连接开启 USB 调试的 Android 设备。
3. 执行 `adb install -r app\build\outputs\apk\debug\app-debug.apk`，或安装提交包中的 debug APK。
4. 打开“灵感工坊”，默认可使用演示模式完成本地流程。

## 模型配置方式

在设置页切换为真实模式后，填写当前配置的 Base URL、API Key、Text Model、Vision Model、图片生成接口类型、图片生成接口地址和图片生成模型。真实 Key 只在设备本地输入和保存，不随代码、文档或日志提交。

## 演示模式 / 真实模式

演示模式不上传用户输入或图片，使用本地 Mock 模板生成带有“演示模式生成”标识的内容，适合离线演示和流程验证。真实模式使用用户配置的兼容接口调用文本、视觉或图片生成模型，网络、鉴权、限流、接口格式等错误会以可读提示展示，不伪装成真实成功。

## 演示场景

1. 朋友圈文案：输入事件或心情，选择风格，生成单版或 3 个版本。
2. 商品描述：输入商品信息，生成克制、结构清楚的商品文案。
3. 图片描述：导入图片或使用示例图，生成客观描述、社交配文或商品文案。
4. 图片生成：输入图片描述，选择风格和比例，生成图片并保存、分享、收藏。

## 本地加密存储概述

应用使用 Android Keystore 生成不可导出的 AES 256 bit 密钥，使用 AES-GCM、随机 IV 和版本化 payload 加密 API Key、文本历史和历史元数据。新生成图片文件长期保存在 `files/generated_images_encrypted/`，预览、分享或保存到相册时才临时解密到 cache。保存到系统相册的图片属于用户主动导出的明文副本。

## 异常处理

应用处理未配置 API Key、Base URL 或模型名为空、网络失败、鉴权失败、限流、服务端错误、图片读取失败、旧图片不可用、图片生成失败等场景，并向用户显示可读提示。

## 已知边界

本地加密不声称抵御 root 设备、恶意系统、运行时截屏、内存读取或用户主动分享后的外部传播。历史记录以本地加密 JSON 保存，适合比赛阶段演示，不面向大规模搜索和云端协作。
